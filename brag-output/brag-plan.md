# Brag Plan: Emily OS

## What is this app?
Emily OS is an AI-native desktop operating platform for Windows 11. It runs durable, multi-agent missions that actually use the computer — native Windows control, a real browser, on-device vision and voice — and keeps everything observable on a tamper-evident audit chain. One kernel, nineteen packages, all local-first.

## The angle
A WHAT / WHY / HOW / SO-WHAT story for a LinkedIn audience, not a feature list. **WHY:** modern work is scattered across dozens of apps that share nothing, and AI that can only talk doesn't help. **WHAT:** Emily OS — an operating system where the intelligence is built in. **HOW:** missions rather than prompts (a supervised agent team plans, executes, verifies, retries) that act on the real machine, hear you in 23 languages, and remember through a continuous world model. **SO-WHAT:** one live control plane, local-first, every action on a hash-chained ledger. The video shows the actual product — the reality of the machine, the mission graph, the voice loop, the world model, and real Emily UI — with a strong music build that drops exactly when the product starts acting.

## Hook (first ~4.5 seconds)
"Your work lives in fifty tabs." → "Fifty apps. Zero memory." → "And the AI can only talk." A problem the audience feels, stated plainly, over a strip of fading browser tabs. Then the turn: "So we built Emily OS."

## Key moments (the middle)
- **What it is.** The presence form opens and the product names itself: "So we built Emily OS." / "An AI-native desktop operating platform." / "It reasons. It acts. It stays observable."
- **How — Missions, not prompts.** A five-stage pipeline assembles on the beat: PLAN → EXECUTE → VERIFY → REFLECT → FINALIZE, with a supervised agent team that plans, verifies, and retries.
- **How — It uses your computer.** DESKTOP (open, click, type, run), BROWSER (navigate, ground, eval), VISION (read the screen) — landing on the music's drop.
- **How — It hears and remembers.** A live voice waveform and language chips (EN, বাংলা, हिन्दी, ES, FR, 中文, 日本語, +23), then a world-model graph: "16 kinds of memory. One continuous world model."
- **The cockpit.** Real Emily UI on screen — the Workbench — with the glass command dock (Screen Vision, Code Review, AST Index, Look Around, Portfolio, Identify Song).
- **Why it holds up.** A hash chain links across the screen: "Local-first. Hash-chained. Human-approved." / "Every action lands on a tamper-evident audit chain."

## Outro / punchline
EMILY OS wordmark lands, then the tagline: **"Quietly capable. Always observable."** Fade to black.
